# Browser demo assets

The hosted build contains the original Tomb Raider I PC demo's title and
City of Vilcabamba level, not the full retail game.

Source archive: https://lostartefacts.dev/aux/trx/tr1-demo-pc.zip
Source project: https://github.com/LostArtefacts/TRX/blob/develop/tools/download_assets
Distribution context: https://lostartefacts.dev/trx/install_guide/develop/
(the installation guide identifies the PC demo as freely distributable content).

Archive entries are copied unchanged to assets/level/1/TITLE.PHD and LEVEL2.PHD.

holders; the engine's BSD 2-Clause license does not apply to these assets.
No retail levels or external soundtrack files are bundled.
